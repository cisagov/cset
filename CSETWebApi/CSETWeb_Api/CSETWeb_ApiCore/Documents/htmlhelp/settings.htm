Settings

 
Users can select the Settings option from the User Profile dropdown menu to display the Settings window.
 

Encrypt Assessment Export

  • Toggle the button to the right to require password encryption for assessment exports.
  • The toggle will display in blue when enabled.
  • When enabled, the Export Assessment Options window will display upon selecting the Export button.
Top

User Language

  • Use the dropdown field to select one of the following available user languages. Translations are only available for the specified assessments.
  • English (Default)
  • Spanish
  • Automated Cybersecurity Evaluation Toolbox (ACET)
  • Ukrainian
  • Cybersecurity Framework 2.0 (CSF 2.0)
  • Translation is available only in Requirements Mode.
  • Cybersecurity Framework 1.1 (CSF 1.1)
  • Translation is available only in Requirements Mode.
  • Ransomware Readiness Assessment (RRA)
  • Cybersecurity Performance Goals (CPG)
Top

CISA Assessor

  • Toggle the button to the right to enable CISA Assessor mode.
  • CISA Assessor mode is turned off by default.
  • The toggle will display in blue when enabled.
  • Note: When CISA Assessor mode is enabled, completion of all Organization Demographics, Assessment Configuration, and Critical Service Information fields are required to access assessment reports and exports.
Top

Close

  • Select the Close button to save any changes and exit the Settings window.
