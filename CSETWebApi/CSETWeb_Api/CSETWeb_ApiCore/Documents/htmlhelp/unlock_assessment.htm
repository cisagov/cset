Unlock Assessment

 
Selecting the Enter Password button opens the Unlock Assessment window.
 

Password

  • Enter the assessment password into the Password field.
  • Note: Assessment passwords are created upon export on the Export Assessment Options window.
Top

Password Hint

  • If applicable, the window displays the password hint created upon export on the Export Assessment Options window.
Top

Cancel

  • Select the Cancel button to exit the Unlock Assessment window.
Top

Continue

  • Select the Continue button to submit the password.
  • If correct, CSET will import the assessment and the assessment will display in the My Assessments list.
  • If incorrect, a File Import Failed message will display on the CSET File Import window.
